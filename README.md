## プロジェクト概要
本プロジェクトは、大学のオープンキャンパスにて、来場する高校生にAI（人工知能）と触れ合う体験を提供するために開発した体験型システムです。
空中に絵を描く（ジェスチャー操作）という直感的なインターフェースと、AIによるリアルタイムの画像判定を組み合わせることで、大学の研究への興味を惹きつけることを目的としています。

- **ターゲット:** オープンキャンパスに来場する高校生
- **目的:**
  1. AI技術を身近に感じるエンターテインメント体験の提供
  2. 体験を通じた学科の研究内容（AI・データサイエンス）への興味喚起
  3. 実機運用を通じたデータ収集（ログ解析・UI/UX改善）

## システム環境構成
- **ハードウェア:** ノートPC, 外付けWebカメラ, モニター
- **開発言語:** Python 3.11
- **主要ライブラリ:**
  - **骨格推定:** MediaPipe Hands (v0.10)
  - **画像処理・UIUI描画:** OpenCV
  - **AIモデル構築:** PyTorch
- **学習データ:** [Quick, Draw! Dataset](https://quickdraw.withgoogle.com/data) (Google)

## コア機能と処理ロジック

### 1. 空中お絵描き（ジェスチャー操作）インターフェース
MediaPipe Handsを用いてWebカメラ映像からユーザーの手の骨格をリアルタイムに検出します。
- **ピンチ判定:** 親指の先端(Landmark 4)と人差し指の先端(Landmark 8)のユークリッド距離を計算し、閾値(`PINCH_THRESHOLD`)以下であれば「ペンON（描画）」、閾値より大きければ「ペンOFF（移動）」と判定。
- **視覚フィードバック:** ペンOFF時は白枠の円形カーソル、ペンON時は赤色の円形カーソルが表示され、軌跡がキャンバスに描画されます。

### 2. CNNによるリアルタイム画像推論
ユーザーが描いた線をAIが分類します。
- **学習モデル:** 5カテゴリ（`clock`, `cat`, `apple`, `cake`, `boomerang`）を分類する独自の畳み込みニューラルネットワーク(CNN)をPyTorchで構築し、事前学習済みの重み(`quickdraw_cnn.pth`)を使用。
- **推論前処理:** 画面中央の正方形ガイド枠内の画像を切り出し、グレースケール化後、28x28ピクセルにリサイズ・正規化してAIモデルに入力します。

## 操作仕様（管理者用コマンド）
| キー | アクション |
| :--- | :--- |
| **A** | AIにお題を予想させる（推論実行） |
| **O** | 予想が「正解」だった場合にログ(`ai_log.csv`)を保存 |
| **X** | 予想が「不正解」だった場合にログ(`ai_log.csv`)を保存 |
| **C** | キャンバスを消去（クリア） |
| **R** | キャリブレーションを開始 / やり直し |
| **F** | プログラムの終了 |

## 開発の工夫点
- **4点キャリブレーション:** 体験者の立ち位置や体格に合わせて、空中の操作範囲を画面サイズにマッピングする機能を搭載（起動時・Rキーで実行）。
- **推論の完全ローカル化:** 会場のネットワーク環境に依存せず、MacBookのGPU(`mps`)を活用することで、高速かつ安定したオフライン推論を実現しました。
- **UI/UXの改善:** 実運用での課題（画面端への描画、アスペクト比の違いによる表示崩れなど）に対し、OpenCVを用いたパディング処理や描画制限を追加することで、体験価値を向上させました。
- **データドリブンな改善:** CSVログ出力機能と事後アンケートを組み合わせることで、AIの精度やユーザー体験を定量的に評価・改善（PDCA）できる仕組みを構築しました。
